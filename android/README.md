# Ruflo Companion for Android

`android/` هو تطبيق Android أصلي مرافق لـ Ruflo، مكتوب بـ Kotlin وJetpack Compose. يقدّم شاشة مراقبة خفيفة للوكلاء الذين تديرهم بوابة Ruflo متوافقة، ولا يستبدل واجهة Ruflo أو خادمها.

## المتطلبات والبناء

يتطلب البناء Android Studio Ladybug أو أحدث، وJDK 17، وAndroid SDK Platform 35. يحتوي هذا المجلد على Gradle Wrapper، ولذلك يمكن تنفيذ الأوامر التالية من داخله:

```bash
./gradlew test
./gradlew assembleDebug
```

ينتج ملف APK التجريبي في `app/build/outputs/apk/debug/`.

## الاتصال بالبوابة

من شاشة **اتصال آمن** في التطبيق، أدخل عنوان HTTPS لبوابة Ruflo الخاصة بك، مثل `https://ruflo.example.com`. يمكن إضافة رمز Bearer عند الحاجة؛ يخزن التطبيق العنوان والرمز باستخدام `EncryptedSharedPreferences` وحماية Android Keystore.

لا يقبل التطبيق عناوين `http://` عن قصد، كما أن إعداد Android يمنع الاتصالات النصية غير المشفّرة.

## عقد الواجهة الشبكية

يتصل التطبيق بنقطة نهاية واحدة في هذه النسخة:

| الطلب | الاستجابة المقبولة | الغرض |
|---|---|---|
| `GET /api/v1/agents` | مصفوفة من الوكلاء، أو كائن JSON يحتوي `agents` أو `data` كمصفوفة | عرض حالة الوكلاء |

يقبل كل وكيل الحقول `id` و`name` و`role` و`status` و`currentTask`. تدعم القراءة أيضًا الاسمين البديلين `agent_id` و`type` و`task` لتسهيل التكامل مع بوابات قائمة.

مثال استجابة:

```json
{
  "agents": [
    {
      "id": "reviewer-01",
      "name": "مراجع الأمن",
      "role": "security-reviewer",
      "status": "running",
      "currentTask": "فحص التغييرات الأخيرة"
    }
  ]
}
```

> التطبيق لا يفترض أن Ruflo الأساسي يوفّر واجهة REST بهذا المسار. شغّل بوابة/محوّلًا مصادقًا في بنيتك ليعرض هذه الواجهة فوق أدوات Ruflo أو خدمته الداخلية، ثم وجّه التطبيق إليها.

## حدود النسخة الأولى

يركّز التطبيق الحالي على إعداد الاتصال الآمن والمراقبة للقراءة فقط. لا ينفّذ أوامر تشغيل أو إيقاف للوكلاء من الهاتف، وذلك لتجنّب إنشاء قناة تحكم عن بعد قبل توثيق نموذج التفويض والتدقيق في البوابة.
